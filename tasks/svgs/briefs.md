# SVG briefs

Twenty drawing briefs, each with a task-specific rubric.

| Task | Instruction |
|---|---|
| `pelican_bicycle` | Generate an SVG of a pelican riding a penny-farthing bicycle while balancing a tiny lighthouse on its head. |
| `octopus_typist` | Generate an SVG of an octopus typing a love letter on a typewriter at the bottom of the sea. |
| `snail_city` | Generate an SVG of a giant snail whose spiral shell supports a miniature city with a crescent-moon streetlamp. |
| `jellyfish_keys` | Generate an SVG of a floating jellyfish holding an umbrella while brass keys rain around it. |
| `fox_violin` | Generate an SVG of a fox playing a violin in a paper boat on a river of musical notes. |
| `teapot_whale` | Generate an SVG of a whale shaped like a teapot pouring a stream of stars into a cloud teacup. |
| `mushroom_astronaut` | Generate an SVG of a mushroom astronaut planting a fork-shaped flag on a cheese moon. |
| `crab_hourglass` | Generate an SVG of a crab carrying an enormous hourglass filled with tiny fish instead of sand. |
| `giraffe_accordion` | Generate an SVG of a giraffe whose long neck is an accordion, performing beneath a striped circus canopy. |
| `owl_lighthouse` | Generate an SVG of an owl lighthouse keeper with a lighthouse for a hat sending beams across a purple sea. |
| `cactus_skater` | Generate an SVG of a cactus on roller skates carrying a tray of three tiny rainclouds. |
| `goldfish_balloon` | Generate an SVG of a goldfish-shaped hot-air balloon lifting a basket of floating water lilies. |
| `crocodile_librarian` | Generate an SVG of a bespectacled crocodile librarian catching flying books with a butterfly net. |
| `robot_gardener` | Generate an SVG of a robot watering a garden of ringed planets sprouting from flowerpots. |
| `pangolin_baker` | Generate an SVG of a pangolin baker rolling dough beneath a giant croissant-shaped moon. |
| `penguin_gramophone` | Generate an SVG of a penguin listening to a gramophone whose horn is an iceberg. |
| `frog_conductor` | Generate an SVG of a frog conductor directing an orchestra of mushrooms with a lightning-bolt baton. |
| `raccoon_comet` | Generate an SVG of a raccoon washing a comet in a wooden washtub beneath a clothesline of stars. |
| `moth_telephone` | Generate an SVG of a moth using an antique telephone that grows out of a giant flower. |
| `turtle_greenhouse` | Generate an SVG of a turtle with a glass greenhouse shell containing a clockwork tree. |
